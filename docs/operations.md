# 運用の手順（1万円・1株単位）

**注文は出しません。** 売買候補を出し、あなたが証券会社のアプリで発注し、約定をここに記録します。
出力は検証ツールの結果であって、投資助言ではありません。結果は保証されません。

## 位置づけ

- 目的は **利益を出すこと** ではなく、**約定がバックテストの想定とどれだけずれるかを測ること**
- 候補の戦略（`regime_hold`）に優位性は確認されていない（開発期間で、N回試した水準を超えていない）。
  1万円で動かすのは、仕組みと約定の想定を検証するため
- 資金を増やすのは、「増額の条件」を全部満たしたときだけ

## 二つのプロファイル

| | `paper` | `live` |
|---|---|---|
| 約定 | 仮想（始値 ± 想定のずれ） | あなたが発注した実際の約定を手入力 |
| データが古いとき | 過去を再生できる | **候補を出さない** |
| 台帳 | `state/ops_paper.db` | `state/ops_live.db` |

ペーパーのスリッページは、仮想約定に想定値を入れているので、必ず想定どおりになる。
**実運用の計測ではない**。そのため、増額の条件のスリッページは、ペーパーの約定を数えない
（ペーパーだけでは、増額の条件を満たさない）。

## 実運用ができない理由（今は）

J-Quants の Free プランは **12週間遅れ** のデータ。候補は最新の相場で作る必要があるため、
`live` の `plan` は、データが5日より古いと拒否する。実運用を始めるには、新しいデータの入手手段が要る
（J-Quants の有料プラン、または別のデータ源。価格と条件は要確認）。

## 手順

```bash
# 1. 戦略を凍結して始める（コミットしてから。凍結した版を再現するため）
python scripts/ops.py --profile live init --cash 10000 --param ma=50

# 2. 引け後に、売買候補を出す
python scripts/ops.py --profile live plan

# 3. 翌営業日、証券会社のアプリで発注し、約定を記録する
python scripts/ops.py --profile live fill --symbol 2012 --side buy --qty 4 --price 246 --signal-id 1

# 4. 状況と増額の条件を見る
python scripts/ops.py --profile live status
```

## 画面（GUI）で操作する

```bash
pip install -e ".[gui]"   # 初回だけ
make gui                  # または python scripts/gui.py
```

ブラウザで http://127.0.0.1:8501 を開く。**このMacからだけ接続できる**（`.streamlit/config.toml`）。

| 画面 | できること |
|---|---|
| 今日 | 実行モード、評価額、保有、増額の条件、データの鮮度 |
| 売買候補と約定 | 候補を作る、約定を記録する、ペーパーで過去を再生する |
| 設定 | 実行モード、リスク制限（緩める変更は24時間後）、キルスイッチ |
| 履歴 | 評価額の推移、約定、候補、監査ログ |
| FX検証（ダミーデータ） | 値動きの性質・戦略・スプレッドを変えて試す。**成績の根拠にはならない** |

画面と CLI（`scripts/ops.py`）は、同じ台帳とキルスイッチを使う。どちらから操作してもよい。
APIキーは画面に出さない（「設定済み / 未設定」だけ）。

## 安全装置

| 機能 | 動作 |
|---|---|
| 凍結 | `init` で戦略とパラメータを固定。変えるなら新しい台帳で始める |
| 古いデータの拒否 | 実運用で5日より古いデータからは候補を出さない |
| リスク制限 | 1注文の上限、1銘柄の上限、同時保有数、日次損失。売りは常に通す |
| 制限の変更 | 厳しくする変更は即時。緩める変更は24時間後に有効 |
| キルスイッチ | `kill` で停止し、候補を出さない（約定の記録はできる）。`resume` で再開 |
| 監査ログ | 設定の変更はすべて追記される（`audit`） |
| 未実装のモード | 確認付き・自動の発注は、証券会社との連携が要るため未実装 |

## 増額の条件

次を全部満たすまで、資金を増やさない。感覚で増やすと、偶然の勝ちに乗ってしまう。

継続60日以上 / 約定30件以上 / 実測スリッページが想定の1.5倍以内 /
最大ドローダウン -15% 以内 / 日次損失の上限に触れていない

## 既知の制約

- 単元未満株の約定は、証券会社が定める時刻と価格で行われる。始値で約定する前提は仮定
- 追加スプレッド（片道0.3%）は仮定。証券会社の実測に置き換える
- 手数料は0円の前提
- 買える銘柄と数量は、調整前の価格で決める。株式分割当日の約定は、データと実際がずれる可能性がある
