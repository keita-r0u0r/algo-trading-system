# FX のペーパー運用（前向きの記録）

AI・売買ルール・基準を、**その時点の本物の値段** で判断・約定させて記録します（仮想の約定）。
**注文は出しません。**

AI の判断は、過去のデータでは試せません。AI はモデルが学習した期間の値動きを知っているので、過去で試すと先読みになるためです。
そこで、これから先を前向きに記録して比べます。

## 口座

| 口座 | 判断 |
|---|---|
| `ai` | AI（拡張パーツ）。枠の中で、通貨ペア・向き・リスクの割合・損切り・利確を自由に決める |
| `rule_hourly_breakout` | 1時間足の突破（過去の検証の `hourly_breakout_20` と同じ決まり。損切り50 pips） |
| `buy_and_hold` | ドル円を買って持つ（損切り100 pips） |
| `no_trade` | 一切売買しない |

どの口座も1万円から始め、同じ時刻・同じ値段・同じコスト（API 手数料 0.002%、ずれ 0.1 pips）で並べます。

## 枠（`core/fx/frame.py`）

AI の判断もルールの判断も、ここを通らなければ実行しません。通らなかった判断は、理由と一緒に記録します。

- 選べる通貨ペアは USD_JPY / EUR_JPY / GBP_JPY / AUD_JPY
- 新規には必ず損切りを付ける（10〜150 pips）。利確を付けるなら、損切りの幅の半分以上
- 数量は「1回の損切りで失う割合」から逆算する。上限はリスクの度合い（既定は medium: 1%・5倍まで・1日 −4% で停止）
- 同時に持つ建玉は1つ。向きを変えるなら、いったん閉じる
- スプレッドが 1 pip を超える時、1日の損失の上限に届いた日、キルスイッチ（`state/KILL_fx_paper`）が在る時は、新規を作らない
- 閉じる判断は、いつでも通す

## 動かす

```bash
make paper                                  # 1回進める
python scripts/fx_paper.py --status         # 口座の状態を見るだけ
python scripts/fx_paper.py --risk small     # リスクの度合いを変える（既定は FX_PAPER_RISK、無ければ medium）
```

Cloud Run では、Cloud Scheduler が月〜土の毎時1分に呼びます（[cloud-run.md](cloud-run.md)）。市場が閉まっていれば何もしません。
結果は操作盤の「FX ペーパー」で見られます。記録は `state/fx_paper.jsonl`（追記のみ）です。

## 費用

AI（Gemini 2.5 Flash-Lite）は1回 $0.002 ほどです。1時間に1回なら月に約 $1 で、月の上限（$5）に含まれます。

## 読み方

- 取引が30件に満たないうちは、運の範囲です
- AI と他の口座を比べること自体が多重比較になります。1つの月の結果で決めないでください
- 増額の判断は、取り置いた検証期間と同じく、事前に決めた条件（[operations.md](operations.md)）で行います
